# ETS2 存档编辑器

一款面向《欧洲卡车模拟 2》的本地存档修改工具。直接读取游戏存档文件，所见即所得地修改金钱、经验、车库、地图探索等核心数据；全程自动备份，改坏随时回滚。

- 免安装，解压即用，不写注册表、不留后台进程
- 修改前自动备份，每个存档槽保留最近 15 份
- 内置安全校验：结构异常、数组错位、悬空引用在落盘前拦截
- 支持拖入存档文件直接解密查看

## 安全设计

- **修改即备份**：每次写档前自动快照，保留最近 15 份，任何时候可以回滚
- **写前校验**：结构完整性、数组配平、悬空引用三重检查，增量口径——只拦本次修改新引入的问题
- **原子落盘**：临时文件写入 → 回读校验 → 原子替换，中途断电也不会留下半截存档
- **数据签名**：官方渠道信息与更新元数据均经 Ed25519 签名验证，被篡改的数据不会被采纳
- **自动更新**：启动时检查新版本，更新包经签名与 SHA-256 双重校验后才会安装

## 使用方法

1. 从 [Releases](https://github.com/china888-58/ETS2-Save-Editor/releases) 下载安装包并安装
2. 启动程序，选择游戏（ETS2）与档案，再选择要修改的存档（列表只列手动存档）
3. 在左侧选择功能卡片，按提示操作；改完进游戏读档即可

> 修改存档前请退出游戏；首次使用建议先跑一次「整档案备份」。
